🚀 Deploy a Vercel

Opción 1: CLI (Terminal)

# Instalar Vercel CLI
npm i -g vercel

# Desde este directorio
vercel

# Para producción
vercel --prod

Opción 2: Interfaz Web

  1. Ve a vercel.com
  2. Crea una cuenta (gratis)
  3. Click en "Add New Project"
  4. Arrastra esta carpeta o conecta desde Git
  5. Click en "Deploy"
💡 Consejo: Lee el archivo DEPLOYMENT.md para instrucciones detalladas.
