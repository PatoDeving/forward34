# 🚀 Cómo Empezar con Forward34

## ✅ Paso 1: Verificar que Node.js está instalado

Abre una **NUEVA terminal** (PowerShell o CMD) y ejecuta:

```bash
node --version
npm --version
```

Si ves las versiones (ejemplo: `v20.11.0` y `10.2.4`), ¡perfecto! Continúa al Paso 2.

Si NO ves las versiones, cierra la terminal actual y abre una **nueva**.

---

## 🎯 Paso 2: Instalar dependencias del proyecto

Desde **este directorio**, ejecuta:

```bash
npm install
```

Esto instalará `http-server` que es todo lo que necesitas.

---

## 🌐 Paso 3: Iniciar el servidor

```bash
npm run dev
```

O también:

```bash
npm start
```

El sitio se abrirá automáticamente en: **http://localhost:3000**
